Rangkuman:

A.Prompt Engineering

Prompt Engineering merupakan cara merancang instruksi agar AI dapat memberikan jawaban yang tepat, relevan, dan sesuai dengan kebutuhan pengguna.
Prompt adalah instruksi atau masukan yang diberikan kepada model AI untuk memperoleh hasil tertentu.
Struktur prompt yang bagus memiliki role, task, context, dan format.
Keuntungan prompt engineering adalah dapat meningkatkan performa AI model, mengurangi bias dan respon yg offensive, meningkatkan kontrol dan predictability, dan memberikan pengalaman prompting yg lebih baik.

B. Git dan GitHub

Git adalah version control system—yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file.
Workflow git: Working directory -> Staging area -> Git directory.
GitHub adalah platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi.
